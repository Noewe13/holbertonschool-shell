   # Basics
 0-current_working_directory : affiche le chemin absolu du repertoire courant
 1-listit : affiche la liste du contenu du repertoire courant
2-bring_me_home : va dans le repertoire personnel de l'utilisateur
3-listfiles : affiche le contenu du repertoire courant en format long
4-listmorefiles : affiche le contenu du repertoire courant en format long, fichiers caches compris
5-listfilesdigitonly : affiche tout le contenu du repertoire courant en format long, avec les ID utilisateur et groupe en nombres
6-firstdirectory : cree le dossier my_first_directory dans /tmp
7-movethatfile : deplace le fichier betty de /tmp vers /tmp/my_first_directory
8-firstdelete : supprime le fichier betty dans /tmp/my_first_directory
9-firstdirdeletion : supprime le dossier my_first_directory dans /tmp
10-back : revient dans le repertoire precedent
